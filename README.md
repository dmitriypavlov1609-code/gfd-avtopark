# ГФД Автопарк — система учёта

Веб-система учёта транспорта и магазинов сети ГФД.

## Разделы
- **Собственный автопарк** — учёт своих ТС: статус, пробег, водитель, магазин, затраты.
- **Привлечённый автопарк** — арендованные ТС: контрагент, договор, ставка, срок, статус.
- **Магазины** — сеть магазинов и закреплённый транспорт.
- **Статистика** — сводная аналитика (расширяется).

## Технологии
Статический фронтенд (HTML/CSS/JS без зависимостей), деплой на Vercel. Светлая/тёмная тема, адаптив.

## Запуск
Открыть `public/index.html` или задеплоить каталог как статический сайт (Vercel).

Live: https://gfd-avtopark.vercel.app
